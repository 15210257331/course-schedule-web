# TeacherOS · 项目功能需求说明书

> 项目名称：TeacherOS · 兼职教师工作台
> 前端：Vue 3 + Vite + Element Plus + Pinia + Vue Router + ECharts + axios + dayjs
> 后端：Spring Boot + MyBatis + MySQL + JWT + BCrypt + Lombok
> 本文档基于当前前后端代码实际功能整理，作为项目介绍与功能需求说明书。

---

## 一、项目概述

TeacherOS 是一款面向兼职教师的「课程与收入管理」工作台。教师可以排课、看课、管理学生/机构、统计收入、在课前收到到点提醒，并附带附件（课件/作业/讲义）上传管理能力。

系统采用前后端分离架构：

- **前端**：提供全部界面交互与数据可视化，通过 REST 接口与后端通信，使用 JWT 令牌维护登录态，桌面端与移动端均可用（响应式布局）。
- **后端**：提供 REST API，采用 JWT 无状态认证 + 线程级用户上下文，所有业务数据按 `user_id` 隔离；通过定时任务完成课程状态自动结算与到点提醒生成。

系统包含两类角色：

| 角色 | 说明 |
|---|---|
| 教师（TEACHER） | 默认角色，使用排课、学生/机构管理、收入统计、个人中心等功能 |
| 管理员（ADMIN） | 管理端，管理教师账号、发布公告消息、查看运营数据看板 |

---

## 二、账号与权限

1. 支持**登录**与**注册**两种进入方式（登录页含「登录 / 注册」两个 Tab，以及「忘记密码」）。
2. 登录成功后本地持久化 `token` 与用户信息（`localStorage`），后续请求通过 `Authorization: Bearer <token>` 携带令牌。
3. 密码使用 BCrypt 加盐哈希存储；JWT 签名密钥通过环境变量注入。
4. 路由守卫：
   - 未登录访问受保护路由时，自动跳转登录页并携带 `redirect` 回跳参数。
   - 教师登录后进入课程日历（默认页）；管理员登录后进入数据看板。
   - 教师访问管理端页面会被重定向到课程表；管理员访问教师端页面会被重定向到数据看板。
5. 支持退出登录（二次确认）。

## 四、教师端功能需求

### 4.1 登录 / 注册 / 忘记密码

- 用户名 + 密码登录，回车快捷提交。
- 注册：用户名（必填）、昵称（可选）、密码（至少 6 位）、确认密码一致性校验。
- 忘记密码：输邮箱 → 发送验证码（60s 倒计时）→ 输入验证码 + 新密码 → 提交重置。

### 4.2 课程表（默认页）

- **三种视图**：日视图 / 周视图 / 月视图，可切换；默认周视图（可在系统设置中修改）。
- 工具栏：上一段 / 下一段、回到今天、「复制到下周」、新增课程按钮。
- **课程卡片显示**：学生姓名、科目、学段、机构（带机构色标签）、时间。
- **拖拽能力**：
  - 课程在日历中拖动可调整时间（移动课程）。
  - 从右侧「课程模板」面板将模板拖入日历空白处即可排课（周/日视图吸附到整格，月视图默认 9:00 开始）。
- **重复课程**：带重复规则的课程为系列课程，删除时二次确认并连带删除整个系列。
- **周视图统计**：右下角展示本周总节数 / 已上课节数 / 本周收入。
- **新增课程**：弹窗表单，默认时长和课时费自动填充系统配置值。
- 冲突提示：时间段与已有课程重叠时后端拒绝并提示。
- 从提醒中心跳转：定位到指定课程所在日期，切换日视图并高亮该课程。

### 4.3 课程模板

- 模板代表「学生 + 科目 + 课程类型」的快速排课入口，可创建 / 编辑 / 删除。
- 模板卡片展示：标题、课程类型标签、机构标签（或家教地点）、备注摘要。
- 拖入日历空白处快速排课（数据克隆，不影响模板本身）。
- 编辑模板时可选「同步到已排课程」：同步后已排课程的学生、机构、科目、学段、课程类型、地点与备注一并更新（不改变课程时间）。
- **学生唯一**：一个学生只能有一个模板。
- **科目限制**：科目必须是当前用户任教学科之一。

### 4.4 附件

- 附件为独立管理页（路由 `/attachments`），不再挂在课程模板上。
- 支持类型：图片（jpg/jpeg/png/gif/webp）、PDF、Word、Excel、PPT、文本、压缩包，单文件 ≤ 20MB。
- 页面以**用户自定义分组**组织附件：支持新增分组、重命名分组、删除分组（其下附件一并删除）。
- 每个分组右上角有自己的「上传」按钮，上传的文件直接归入该分组；另有「未分组」区收纳历史模板附件及未归组附件。
- 附件列表以**卡片**形式展示，卡片包含：文件缩略图 / 类型图标、文件名、类型标签、文件大小，以及预览 / 下载 / 移动到分组 / 删除操作。
- 图片支持点击放大预览（图片查看器）；PDF 支持在新窗口预览；其余类型仅支持下载。
- 历史挂在模板上的附件一并归入本页统一展示与管理。

### 4.5 工作台

- 欢迎区：显示当前用户昵称。
- 收入统计卡片（从左到右）：今日收入、上月收入、本月收入、本年收入。
- 收入趋势：折线图，支持近 7 / 30 / 90 天切换；横轴日期格式化；副标题展示区间总金额 / 总时长（小时）/ 总节数。
- 收入构成：机构占比、学生占比、学段占比三个环形饼图。
- 今日课程：列出今日课程列表（学生、学段、时间、机构、类型）。

### 4.6 课程管理

- 按时间范围 + 标题模糊分页查询（服务端分页）。
- 新增、编辑（弹窗表单）、删除。
- 新增 / 编辑课程：默认时长和课时费自动填充系统配置值；支持设置提醒时间（默认使用系统配置的提醒偏移）。
- 移动课程：调整起止时间（含冲突校验）。

### 4.7 学生管理

- 学生列表以「课程模板」聚合展示（一个模板代表一个学生）。
- 展示姓名、学段、类型、机构、科目、课时费、备注，支持分页与姓名搜索。
- 学生信息通过课程 / 模板中的姓名字段自动关联（以「姓名」为去重键，录入时自动绑定或自动建档），不再单独维护学生实体。

### 4.8 机构管理

- 机构列表增删改查，支持分页与名称搜索。
- 机构可维护主题色，用于日历 / 列表中的机构标签色。
- 删除保护：机构下存在课程时禁止删除。

### 4.9 费用详情

- 顶部默认统计**上月整月**数据（月份选择组件）。
- 维度切换：学生维度 / 机构维度。
- 结算状态：可标记课程费用是否已结清，用于区分已结清 / 未结清收入。
- 汇总卡片：月份 · 维度数量 · 总节数 · 总费用。
- 明细列表（卡片 + 进度条）：按费用降序排列，每项展示排名、名称、`N节 × 单价 = 费用` 公式、金额与进度条。
- 导出 CSV：按当前维度导出明细（含排名、名称、机构/学生、课程数、单价、费用），Excel 兼容。

### 4.10 个人中心

- 资料展示与编辑：昵称、头像（支持本地上传）、邮箱、手机号、任教学科（下拉单选，从预置学科选择）。
- 修改密码（原密码校验 + 新密码至少 6 位）。
- 数据备份：导出当前用户所有业务数据为 JSON 文件；导入 JSON 文件全量替换数据。
- 清除本地缓存。

### 4.11 系统设置（全局偏好）

| 设置项 | 说明 |
|---|---|
| 默认课程时长（分钟） | 新建课程 / 模板时自动填充 |
| 默认课程提醒（分钟） | 创建课程时若未指定提醒时间则使用此值 |
| 默认课时费（元/小时） | 新建课程 / 模板时自动填充 |
| 浏览器通知开关 | 控制是否弹出系统通知 |
| 默认视图（日/周/月） | 课程日历默认展示 |
| 本地缓存开关（默认关） | 控制是否使用 IndexedDB 缓存 |

### 4.12 提醒中心与消息（顶部铃铛）

- 顶部铃铛合并展示「课程提醒」与「系统消息（公告）」，按时间倒序。
- 未读加粗、角标显示未读数。
- 「全部已读」。
- 课程提醒：每分钟检查到点的课程提醒；若开启浏览器通知并获得授权，弹出系统通知。
- 系统消息：管理员发布的公告 / 活动 / 通知，教师端阅读后标记已读。

### 4.13 主题与响应式

- 亮色 / 暗色主题切换，选择持久化到 `localStorage`，下次访问生效。
- 顶部导航在窄屏折叠为移动端抽屉菜单。

## 五、管理端功能需求（仅 ADMIN）

### 5.1 数据看板

- 统计卡片：教师总数、本月新增教师、本月课程数、消息触达。
- 折线图：新增教师 / 课程数趋势。
- 最新注册教师列表、最新消息列表。

### 5.2 教师管理

- 教师列表分页查询，支持状态筛选（正常 / 已禁用）与关键字搜索。
- 查看教师详情（资料、账号状态、禁用原因、最近登录时间等）。
- **禁用 / 启用**教师账号：禁用后该教师无法登录，可填写禁用原因。
- **重置密码**：管理员为教师重置密码，并通过邮箱发送新密码。

### 5.3 消息推送

- 发布消息：标题、内容、类型（公告 / 活动 / 通知）、目标（全部教师 / 指定教师）。
- 消息状态：已发布 / 已撤回，支持发布、撤回、删除。
- 查看消息详情与已读 / 未读人数统计。
- 教师端通过顶部铃铛接收，阅读后标记已读。

## 六、后端接口约定

- 接口前缀 `/api`，除登录 / 注册 / 重置密码 / 上传外均需 JWT。
- 统一返回结构 `{ code, message, data }`，`code === 0` 表示成功；分页返回 `{ total, list }`。
- 自 v2.0 起，所有查询接口统一改为 **POST** 请求，参数通过 RequestBody 传递；路径采用 `/list`、`/page`、`/detail` 等语义化后缀。
- 文件上传以 `multipart/form-data` 提交，附件返回 `/uploads/**` 相对地址（开发环境经 vite 代理到后端）。

### 主要接口一览

| 模块 | 路径 | 说明 |
|---|---|---|
| 认证 | `/api/auth/**` | 登录、注册、资料查询/更新、改密、重置密码（发送验证码 / 校验重置） |
| 课程 | `/api/courses/**` | 列表、分页、详情、新增、编辑、删除、移动、复制本周到下周 |
| 课程模板 | `/api/course-templates/**` | 列表、分页、详情、新增、编辑、删除 |
| 机构 | `/api/organizations/**` | 列表、分页、详情、新增、编辑、删除 |
| 工作台统计 | `/api/dashboard/**` | 汇总、今日课程、收入报告、更新结算状态 |
| 系统设置 | `/api/settings/**` | 读取、保存 |
| 提醒 | `/api/notifications/**` | 列表、未读到期、标记已读、全部已读、删除 |
| 数据备份 | `/api/backup/**` | 导出、导入 |
| 上传 | `/api/upload/**` | 头像上传、附件上传 |
| 附件 | `/api/attachments/**` | 列表（全部 / 按业务对象）、移动分组、下载、删除 |
| 附件分组 | `/api/attachment-groups/**` | 列表、新增、重命名、删除 |
| 消息（教师端） | `/api/messages/**` | 列表、标记已读、全部已读 |
| 管理端 | `/api/admin/**` | 数据看板、教师管理、消息推送 |

## 七、关键业务规则

- **数据隔离**：所有业务数据按 `user_id` 隔离，接口通过 `UserContext` 获取当前用户。
- **收入/课时统计口径**：以 `end_time < NOW()` 视为「已结束」，跨所有统计一致。
- **课程状态自动结算**：定时任务每分钟将已到期的 `scheduled` 课程批量置为 `completed`。
- **到点提醒生成**：定时任务每分钟在开课前窗口内为课程生成提醒，每节课只生成一次。
- **学生去重**：以「姓名」为去重键，课程 / 模板录入学生姓名时自动绑定或自动建档。
- **默认配置贯通**：系统设置中的默认时长、默认课时费、默认提醒会在新建课程 / 模板时自动填充。
- **机构删除保护**：机构下存在课程时禁止删除。

## 八、数据表结构

| 表 | 说明 | 关键字段 |
|---|---|---|
| `user` | 用户 | username（唯一）、password（BCrypt）、nickname、avatar、email、phone、subjects、role、status、disabled_reason、disabled_at、last_login_at |
| `organization` | 机构 | user_id、name、contact_name、contact_phone、address、color、remark |
| `course` | 课程 | user_id、title、student_name、organization_id、subject、stage、course_type、start_time、end_time、fee、location、note、status、color、reminder_offset_minutes、repeat_type、repeat_end_date、parent_id、template_id |
| `course_template` | 课程模板 | user_id、title、student_name、organization_id、subject、stage、course_type、duration_minutes、fee、location、note、repeat_type |
| `notification` | 提醒 | user_id、type、title、content、course_id、remind_at、is_read |
| `setting` | 用户设置 | user_id、setting_key、setting_value（联合唯一） |
| `settlement` | 结算状态 | user_id、settle_month、target_type、target_key、settled |
| `attachment` | 附件 | user_id、group_id、biz_type、biz_id、file_name、file_path、file_size、mime_type |
| `attachment_group` | 附件分组 | user_id、name |
| `admin_message` | 管理端消息 | title、content、type、target_type、target_ids、status、created_by |
| `admin_message_read` | 消息阅读记录 | message_id、user_id、read_at |

> 表结构通过 `schema.sql` 初始化（`CREATE TABLE IF NOT EXISTS`，幂等）；存量表列的补齐由 `SchemaMigration` 在启动时完成。
