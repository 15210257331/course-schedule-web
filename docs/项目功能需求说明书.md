# TeacherOS · 项目功能需求说明书

> 项目名称：TeacherOS · 兼职教师工作台
> 前端：Vue 3 + Vite + Element Plus + Pinia + Vue Router + ECharts + axios + dayjs
> 后端：Spring Boot + MyBatis + MySQL + JWT + BCrypt + Lombok
> 本文档基于当前前后端代码实际功能整理，作为项目介绍与功能需求说明书。

---

## 一、项目概述

TeacherOS 是一款面向兼职教师的「课程与收入管理」工作台。教师可以排课、看课、管理学生/机构、统计收入、在课前收到到点提醒，并提供独立的「课件管理」能力（课件/作业/讲义上传与维护）。

系统采用前后端分离架构：

- **前端**：提供全部界面交互与数据可视化，通过 REST 接口与后端通信，使用 JWT 令牌维护登录态，桌面端与移动端均可用（响应式布局）。
- **后端**：提供 REST API，采用 JWT 无状态认证 + 线程级用户上下文，所有业务数据按 `user_id` 隔离；通过定时任务完成课程状态自动结算与到点提醒生成。

系统包含两类角色：

| 角色 | 说明 |
|---|---|
| 教师（TEACHER） | 默认角色，使用排课、学生/机构管理、收入统计、个人中心等功能 |
| 管理员（ADMIN） | 管理端，管理教师账号、发布公告消息、查看运营数据看板 |

---

## 二、账号与权限

1. 支持**登录**与**注册**两种进入方式（登录页含「登录 / 注册」两个 Tab，以及「忘记密码」）。
2. 登录成功后本地持久化 `token` 与用户信息（`localStorage`），后续请求通过 `Authorization: Bearer <token>` 携带令牌。
3. 密码使用 BCrypt 加盐哈希存储；JWT 签名密钥通过环境变量注入。
4. 路由守卫：
   - 未登录访问受保护路由时，自动跳转登录页并携带 `redirect` 回跳参数。
   - 教师登录后进入课程日历（默认页）；管理员登录后进入数据看板。
   - 教师访问管理端页面会被重定向到课程表；管理员访问教师端页面会被重定向到数据看板。
5. 支持退出登录（二次确认）。

## 四、教师端功能需求

### 4.1 登录 / 注册 / 忘记密码

- 用户名 + 密码登录，回车快捷提交。
- 注册：用户名（必填）、昵称（可选）、密码（至少 6 位）、确认密码一致性校验。
- 忘记密码：输邮箱 → 发送验证码（60s 倒计时）→ 输入验证码 + 新密码 → 提交重置。

### 4.2 课程表（默认页）

- **三种视图**：日视图 / 周视图 / 月视图，可切换；默认周视图（可在系统设置中修改）。切换视图时按新视图的时间范围重新拉取课程（月视图拉取整月 42 格覆盖的所有日期）。
- 工具栏：上一段 / 下一段、回到当前时段（按钮文案随视图显示「今日 / 本周 / 本月」）、「复制到下周」、新增课程按钮。
- **复制到下一周**：将当前日历所在周的全部课程平移复制到下一周（按周一到周日对齐，已上完的课也一并复制）。带重复规则的系列课不参与整周复制（由其自身规则顺延），目标时段已有课的节跳过；复制后提示「已复制 N 节，跳过 M 节（X 节重复课，Y 节时段冲突）」。
- **课程卡片显示**：学生姓名、科目、学段、机构（带机构色标签）、时间。
- **拖拽能力**：
  - 课程在日历中拖动可调整时间（移动课程），移动成功后弹出「课程时间已更新」提示。
  - 从左侧「学生列表」面板将学生拖入日历空白处即可排课（周/日视图吸附到整格，月视图默认 9:00 开始）。
- **左侧学生面板**：以「学生」为维度的快速排课入口，默认请求 20 条（服务端分页），支持关键字搜索与新增学生。
- **重复课程**：带重复规则的课程为系列课程，删除时二次确认并连带删除整个系列。
- **右下角统计**：日/周/月三种视图均展示，统计当前视图时间范围内的总节数 / 已上课节数 / 已上完课程收入，标签随视图切换为「今日 / 本周 / 本月」。
- **月视图展示**：42 格月历（周一起始，含月初/月末补齐的相邻月份日期），每格显示日期、「N 节」课程数角标，以及最多 3 条课程条目（时间 + 标题，超出的折叠为「+N 更多」）；非本月日期置灰，点击任意日期切换到该日的日视图，双击课程条目打开课程详情。
- **新增课程**：弹窗表单，默认时长和课时费自动填充系统配置值。
- 冲突提示：时间段与已有课程重叠时后端拒绝并提示。
- 从提醒中心跳转：定位到指定课程所在日期，切换日视图并高亮该课程。

### 4.3 学生

- 学生是排课的核心实体（独立的 `student` 数据表，`id` 为唯一标识），代表「学生 + 科目 + 课程类型」的快速排课入口，可创建 / 编辑 / 删除。
- 学生卡片展示：标题（姓名）、课程类型标签、机构标签（或上课地点）、备注摘要；有课件的学生在卡片右下角显示回形针图标（数量在悬浮提示中展示），点击可查看该学生的课件列表。
- **课程类型与上课地点/机构联动**：
  - 课程类型选择「家教」时：不显示上课机构，填写「上课地点」（自由文本，如学生家、图书馆等）。
  - 选择其它类型（一对一/班课等）时：不显示上课地点，改为选择「上课机构」（固定宽度下拉）。
  - 机构下拉框后带「+」图标按钮，点击弹出机构新增弹窗（与机构管理中一致），保存后自动刷新机构列表并选中新建机构。
- 学生管理页面与课表页面的学生列表共用同一数据源（同一分页接口）。
- 拖入日历空白处快速排课（拖入时拷贝学生快照到课程，课程记录 `student_id` 关联，不影响学生本身）。
- 编辑学生时可选「同步到已排课程」：同步后该学生已排（非重复系列）课程的学生姓名、机构、科目、学段、课程类型、地点与备注一并更新（不改变课程时间）。
- 删除学生时可选「仅删除学生」或「同时删除课程」（连同该学生名下课程）。
- **学生唯一**：同一教师下学生姓名不可重复，重复时提示「该学生已存在，请勿重复添加」。
- **科目限制**：科目必须是当前用户任教学科之一。

### 4.4 课件管理（独立菜单）

- 课件不再固定属于单个学生，通过「课件-学生」关联表支持**一个课件关联多个学生**，独立为「课件管理」菜单页面维护。
- 支持类型：图片（jpg/jpeg/png/gif/webp）、PDF、Word、Excel、PPT、文本、压缩包，单文件 ≤ 20MB（前端、后端 multipart、网关 nginx `client_max_body_size` 三处上限一致；超限在网关直接返回 413，前端提示「文件过大，超出服务器上传限制」）。
- 顶部统计卡片：课件总数、关联学生数、课件总大小（按当前页统计）。
- 筛选：按学生筛选（下拉，命中该学生关联的全部课件）+ 文件名关键字搜索，支持「重置」和「查询」。
- **上传流程**：点击上传后先弹出「选择学生」对话框，**支持多选**（至少选一个）后开始上传；上传接口同时兼容旧的单 `studentId` 参数。弹窗顶部展示待上传文件名与大小。
- 课件以卡片网格形式展示：类型着色缩略图 / 类型图标、文件名、关联学生（顿号拼接的多个姓名，最多两行）、类型标签、文件大小、上传时间；卡片网格**在区域内滚动**，不撑长整页。
- 图片支持点击放大预览（图片查看器）；PDF 支持内嵌预览；其余类型仅支持下载。
- **修改关联学生**：每张课件卡片提供「修改关联学生」操作，弹窗中重新多选学生后全量覆盖保存（至少一个）。
- 学生侧视图：学生卡片上有课件标识（回形针 + 数量），hover 显示「N 个课件」；点击打开的课件弹窗中，每个课件同时展示其关联的全部学生姓名。
- 删除学生时级联解除其课件关联；因此不再被任何学生关联的课件连同磁盘文件一并删除。
- 删除课件时连带删除其全部学生关联与磁盘文件。

### 4.5 工作台

- 欢迎区：显示当前用户昵称。
- 收入统计卡片（从左到右）：今日收入、上月收入、本月收入、本年收入。
- 收入趋势：**收入折线 + 每日上课数量柱状（双 Y 轴）**组合图，带图例（收入 / 上课数量）；支持近 7 天 / 近 1 个月 / 近 3 个月切换；横轴日期格式化；副标题展示区间总金额 / 总时长（小时）/ 总节数；收入只统计已结束课程，上课数量按课程开始时间归天统计。
- 收入构成：机构占比、学生占比、学段占比三个环形饼图，**标签与悬浮提示只显示名称和百分比**（不显示金额）。
- 今日课程：列出今日课程列表（学生、学段、时间、机构、类型）；每条课程带「在课表中查看」图标，点击跳转课表页并定位到该课程所在日的日视图。
- 图表卡片区域加载时有 loading 遮罩。

### 4.6 课程管理

- 「新增课程」「导出」按钮位于页面右上角，与页面标题同行（新增课程在前，导出在后）。
- 筛选条件：时间范围（固定宽度，默认前后一个月）、**学生姓名（可联想下拉，选项来自学生管理，按姓名精确匹配）**；「重置」和「查询」靠右。
- 按筛选条件分页查询（服务端分页）；导出 CSV 时按当前筛选条件导出。
- 新增、编辑（弹窗表单）、删除。
- 新增 / 编辑课程：默认时长和课时费自动填充系统配置值；支持设置提醒时间（默认使用系统配置的提醒偏移）。
- 移动课程：调整起止时间（含冲突校验）。

### 4.7 学生管理

- 学生为独立实体（`student` 表），不再通过课程聚合，支持新增、编辑、删除，与课表页面的操作行为完全一致：
  - 编辑学生时可选择「同步到已排课程」或「仅修改学生」。
  - 删除学生时可选择「仅删除学生」或「同时删除课程」。
- 「新增学生」「导出」按钮位于页面右上角，与页面标题同行。
- 筛选条件：姓名模糊、学段、课程类型、机构；「重置」和「查询」靠右。
- 列表展示：姓名、学段、类型、机构、上课地点（有机构时显示机构地址，否则显示自定义地点）、课时费、课件（回形针图标，悬浮显示数量）、备注；不展示科目列。
- 点击课件图标可弹窗查看该学生的课件列表（卡片形式：类型着色缩略图、文件名、类型标签、大小、上传时间，支持预览 / 下载 / 删除；每个课件同时展示其关联的全部学生姓名）；课表左侧学生卡片上的回形针同样可打开该弹窗。
- 支持分页，与课表页学生列表共用同一数据源。
- 导出 CSV：按当前筛选条件导出学生列表（姓名/学段/类型/机构/上课地点/课时费/课件数/备注）。

### 4.8 机构管理

- 「新增机构」按钮位于页面右上角，与页面标题同行，「导出」按钮紧随其后。
- 筛选条件：名称模糊、地址模糊；「重置」和「查询」靠右；支持分页。
- 机构表单：名称必填、**地址必填**，不再维护联系人与联系电话。
- 机构可维护主题色，用于日历 / 列表中的机构标签色，以及费用详情页机构行进度条颜色。
- 删除保护：机构下存在课程时禁止删除。
- 导出 CSV：按当前筛选条件导出机构列表（机构名称/地址/备注），Excel 兼容。

### 4.9 费用详情

- 顶部默认统计**本月整月**数据（月份选择组件）。
- 维度切换：学生维度 / 机构维度。
- 结算状态：可标记课程费用是否已结清，用于区分已结清 / 未结清收入。
- 汇总卡片：月份 · 维度数量 · 总节数 · 总费用。
- 明细列表（卡片 + 进度条）：按费用降序排列，每项展示排名、名称、`N节 × 单价 = 费用` 公式、金额与进度条；**进度条颜色按行取色：机构行使用机构维护的主题色，家教等无机构的行使用自定义配色（按名称哈希取色，同名稳定同色）**；机构行在机构名后按学生逐个展开「学生标签 + 公式」，家教行按「家教-学生」单独成行并直接展示公式。
- 导出 CSV：按当前维度导出明细（含排名、名称、机构/学生、课程数、单价、费用），Excel 兼容。

### 4.10 个人中心

- 资料展示与编辑：昵称、头像（支持本地上传）、邮箱、手机号、任教学科（下拉单选，从预置学科选择）。
- 修改密码（原密码校验 + 新密码至少 6 位）。
- 数据备份：导出当前用户所有业务数据为 JSON 文件；导入 JSON 文件全量替换数据。
- 清除本地缓存。

### 4.11 系统设置（全局偏好）

| 设置项 | 说明 |
|---|---|
| 默认课程时长（分钟） | 新建课程 / 学生时自动填充 |
| 默认课程提醒（分钟） | 创建课程时若未指定提醒时间则使用此值 |
| 默认课时费（元/小时） | 新建课程 / 学生时自动填充 |
| 浏览器通知开关 | 控制是否弹出系统通知 |
| 默认视图（日/周/月） | 课程日历默认展示 |
| 本地缓存开关（默认关） | 控制是否使用 IndexedDB 缓存 |

### 4.12 提醒中心与消息（顶部铃铛）

- 顶部铃铛合并展示「课程提醒」与「系统消息（公告）」，按时间倒序。
- 未读加粗、角标显示未读数。
- 「全部已读」。
- 课程提醒：每分钟检查到点的课程提醒；若开启浏览器通知并获得授权，弹出系统通知。
- 系统消息：管理员发布的公告 / 活动 / 通知，教师端阅读后标记已读。

### 4.13 主题与响应式

- 亮色 / 暗色主题切换，选择持久化到 `localStorage`，下次访问生效。
- 顶部导航在窄屏折叠为移动端抽屉菜单。

## 五、管理端功能需求（仅 ADMIN）

### 5.1 数据看板

- 统计卡片：教师总数、**本月学生数（副标题显示今日新增与累计总数）**、本月课程数、消息触达。
- 折线图：新增教师 / 课程数 / **新增学生**三条趋势线，带图例。
- 最新注册教师列表、最新消息列表。
- 趋势图卡片加载时有 loading 遮罩。
- 顶部导航的**全局搜索仅教师端可见**（搜索课程 / 学生 / 机构），管理端不显示搜索区域。

### 5.2 教师管理

- 筛选条件（状态、关键字）位于列表卡片内左侧，「重置」「查询」靠右。
- 教师列表分页查询，支持状态筛选（正常 / 已禁用）与关键字搜索。
- 查看教师详情（弹窗，含资料、账号状态、禁用原因、最近登录时间等）：
  - **本月统计**：本月总课数、本月已上课数、本月已有收入。
  - **上月统计**：上月总课数、上月收入。
  - 收入口径与教师端一致（`end_time < NOW()` 视为已上）。
- **禁用 / 启用**教师账号：禁用后该教师无法登录，可填写禁用原因。
- **重置密码**：管理员为教师重置密码，并通过邮箱发送新密码。

### 5.3 消息推送

- 发布消息：标题、内容、类型（公告 / 活动 / 通知）、目标（全部教师 / 指定教师）。
- 「发布消息」按钮位于页面右上角，与页面标题同行；筛选条件（类型 / 状态 / 关键字）位于列表卡片内左侧，「重置」「查询」靠右。
- 消息状态：已发布 / 已撤回，支持发布、撤回、删除。
- 消息列表支持类型 / 状态筛选与关键字搜索。
- **阅读明细**：列表中的「阅读数」可点击，弹窗展示目标教师逐个的已读 / 未读状态与阅读时间（未读在前，已读按时间倒序）。
- **消息详情弹窗**：标题行展示类型标签与发布状态；元信息条（目标范围 / 发布时间 / 阅读数）居中收纳，正文区域带边框卡片式展示、超高内部滚动。
- 教师端通过顶部铃铛接收，阅读后标记已读。

### 5.4 操作日志

- 记录全平台关键写操作（登录 / 登录失败、教师管理、消息推送、课程 / 学生 / 机构 / 课件的增删改、状态变更、重置密码、撤回 / 发布、课程移动、整周复制）。
- 筛选条件（模块、动作、关键字）位于列表卡片内左侧，「重置」「查询」靠右。
- 支持按模块（含「学生」模块，历史日志中的「课程模板」保留可查）、动作、关键字（操作人用户名 / 详情）筛选分页查询。
- 每条记录包含：时间、操作人、模块、动作、详情、来源 IP、成功 / 失败结果。
- 同时记录登录失败场景（操作人 / 用户名为空），用于安全审计。

### 5.5 数据备份

- **自动备份**：每天 22:00 自动备份全库关键业务表为 JSON 文件，服务在备份时刻未运行时启动后自动补一次；保留最近 14 份，失败不中断。
- **存储位置切换**：本地目录（默认）与腾讯云 COS 异地备份二选一，切换后立即生效。
- **手动备份**：可随时触发立即备份。
- 备份记录列表展示：备份时间、文件名、触发方式（自动备份 / 手动备份）、存储位置、文件大小、状态（成功 / 失败含失败原因）。
- 支持下载历史备份文件。
- **导入恢复**：上传历史备份 JSON，清空当前业务数据（课程 / 学生 / 机构等，教师账号保留）后全量还原，保留原 id 与外键关系，单事务失败回滚；旧备份中已废弃的表 / 列自动跳过，不报错。

## 六、后端接口约定

- 接口前缀 `/api`，除登录 / 注册 / 重置密码 / 上传外均需 JWT。
- 统一返回结构 `{ code, message, data }`，`code === 0` 表示成功；分页返回 `{ total, list }`。
- 自 v2.0 起，所有查询接口统一改为 **POST** 请求，参数通过 RequestBody 传递；路径采用 `/list`、`/page`、`/detail` 等语义化后缀。
- 文件上传以 `multipart/form-data` 提交，课件返回 `/uploads/**` 相对地址（开发环境经 vite 代理到后端）。

## 七、关键业务规则

- **数据隔离**：所有业务数据按 `user_id` 隔离，接口通过 `UserContext` 获取当前用户。
- **收入/课时统计口径**：以 `end_time < NOW()` 视为「已结束」，跨所有统计一致。
- **课程状态自动结算**：定时任务每分钟将已到期的 `scheduled` 课程批量置为 `completed`。
- **到点提醒生成**：定时任务每分钟在开课前窗口内为课程生成提醒，每节课只生成一次。
- **学生唯一**：同一教师下学生姓名不可重复（以「姓名」为去重键），新增时校验。
- **学生与课程关联**：学生拖入日历排课时，课程记录 `student_id`；编辑学生可选同步到已排课程，删除学生可选连带删除课程。
- **默认配置贯通**：系统设置中的默认时长、默认课时费、默认提醒会在新建课程 / 学生时自动填充。
- **机构删除保护**：机构下存在课程时禁止删除。

## 八、数据表结构

| 表 | 说明 | 关键字段 |
|---|---|---|
| `user` | 用户 | username（唯一）、password（BCrypt）、nickname、avatar、email、phone、subjects、role、status、disabled_reason、disabled_at、last_login_at |
| `organization` | 机构 | user_id、name、address（必填）、color、remark |
| `course` | 课程 | user_id、title、student_id、student_name、organization_id、subject、stage、course_type、start_time、end_time、fee、location、note、status、color、reminder_offset_minutes、repeat_type、repeat_end_date、parent_id |
| `student` | 学生 | id（主键，唯一标识）、user_id、title、student_name（同用户下唯一）、organization_id、subject、stage、course_type、duration_minutes、fee、location、note、repeat_type |
| `course_message` | 课程提醒 | user_id、title、content、course_id、remind_at、is_read |
| `setting` | 用户设置 | user_id、setting_key、setting_value（联合唯一） |
| `settlement` | 结算状态 | user_id、settle_month、target_type、target_key、settled |
| `attachment` | 课件 | user_id、file_name、file_path、file_size、mime_type |
| `attachment_student` | 课件-学生关联 | user_id、attachment_id、student_id（联合唯一），一个课件可关联多个学生 |
| `admin_message` | 管理端消息 | title、content、type、target_type、target_ids、status、created_by |
| `admin_message_read` | 消息阅读记录 | message_id、user_id、read_at |
| `operation_log` | 操作日志 | user_id、username、module、action、target_id、detail、ip、success |
| `backup_record` | 自动备份记录 | file_name、file_path、file_size、storage_type、trigger_type、status、error_msg |

> 表结构通过 `schema.sql` 初始化（`CREATE TABLE IF NOT EXISTS`，幂等）；存量表列的补齐由 `SchemaMigration` 在启动时完成（含 `course_template` → `student` 的历史表自动迁移：将旧模板表重命名为学生表，`course.template_id` 改为 `course.student_id`；课件多学生化迁移：将 `attachment.student_id` 存量数据搬入 `attachment_student` 关联表后清空旧列，保留列结构以幂等判重）。
