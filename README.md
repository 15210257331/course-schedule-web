# TeacherOS 前端（course-schedule-web）需求说明书

> 项目名称：TeacherOS · 兼职教师工作台（前端）
> 技术栈：Vue 3 + Vite + Element Plus + Pinia + Vue Router + ECharts + axios + dayjs

---

## 一、项目概述

TeacherOS 是一款面向兼职教师的「课程与收入管理」工作台。教师可以排课、看课、管学生/机构、统计收入，并在课前收到到点提醒。

前端负责全部界面交互与数据可视化，通过 REST 接口与后端（course-schedule-server）通信；采用 JWT 令牌做登录态维护。本系统在桌面端与移动端均需可用（响应式布局）。

## 三、账号与权限

1. 支持**登录**与**注册**两种进入方式（登录页含「登录 / 注册」两个 Tab）。
2. 登录成功后本地持久化 `token` 与用户信息（`localStorage`），后续请求通过 `Authorization: Bearer <token>` 携带令牌。
3. 未登录访问受保护路由时，自动跳转登录页，并携带 `redirect` 回跳参数。
4. 登录态下访问登录页，自动跳转默认页。
5. 支持退出登录（二次确认）。

## 五、功能需求

### 5.1 登录 / 注册
- 用户名 + 密码登录，回车快捷提交。
- 注册：用户名（必填）、昵称（可选）、密码（至少 6 位）、确认密码一致性校验。

### 5.2 课程日历（默认页）
- **三种视图**：日视图 / 周视图 / 月视图，可切换；默认周视图。
- 工具栏：上一段 / 下一段、回到今天、「复制到下周」、新增课程按钮。
- **课程卡片显示**：学生姓名、科目、学段、机构（带机构色标签）、时间。
- **拖拽能力**：
  - 课程在日历中拖动可调整时间（移动课程）。
  - 从右侧「课程模板」面板将模板拖入日历空白处即可排课（周/日视图吸附到整格，月视图默认 9:00 开始）。
- **重复课程**：带重复规则的课程为系列课程，删除时二次确认并连带删除整个系列。
- **周视图统计**：右下角展示本周总节数 / 已上课节数 / 本周收入。
- 冲突提示：时间段与已有课程重叠时后端拒绝并提示。

### 5.3 工作台
- **欢迎区**：显示当前用户昵称。
- **收入统计卡片**（从左到右）：今日收入、上月收入、本月收入、本年收入。
- **收入趋势**：折线图，支持近 7 / 30 / 90 天切换（切换按钮位于图表上方）；横轴日期格式化，多条时自动旋转刻度。副标题展示区间总金额 / 总时长（小时）/ 总节数。
- **收入构成**：机构占比、学生占比、学段占比三个环形饼图。
- **今日课程**：列出今日课程列表（学生、学段、时间、机构、类型）。

### 5.4 课程管理
- 按时间范围 + 标题模糊分页查询（服务端分页）。
- 新增、编辑（弹窗表单）、复制（复制到次日）、删除。

### 5.5 学生管理
- 学生列表以「课程模板」聚合展示（一个模板代表一个学生）。
- 展示姓名、学段、类型、机构、科目、课时费、备注，支持分页与姓名搜索。

### 5.6 机构管理
- 机构列表增删改查，支持分页与名称搜索。
- 机构可维护主题色，用于日历/列表中的机构标签色。

### 5.7 收入 / 费用详情
- 顶部默认统计**上月整月**数据（月份选择组件）。
- **维度切换**：学生维度 / 机构维度。
- 汇总卡片：月份 · 维度数量 · 总节数 · 总费用。
- **明细列表（卡片 + 进度条）**：按费用降序排列，每项展示排名、名称、`N节 × 单价 = 费用` 公式、金额与进度条。
  - 学生维度：名称 + 对应机构。
  - 机构维度：名称 + 该机构下所有学生姓名（以 `·` 分隔）。
- **导出 CSV**：按当前维度导出明细（含排名、名称、机构/学生、课程数、单价、费用），Excel 兼容。

### 5.8 个人中心
- 资料展示与编辑：昵称、头像（支持本地上传）、邮箱、手机号、任教学科（下拉单选，从预置学科选择）。
- 修改密码（原密码校验 + 新密码至少 6 位）。
- 清除本地缓存。

### 5.9 系统设置（全局偏好）
- 默认课程时长（分钟）
- 默认课程提醒（分钟）
- 默认课时费（元/小时）
- 浏览器通知开关
- 默认视图（日 / 周 / 月）
- 本地缓存开关（默认关）

### 5.10 忘记密码
- 登录页「忘记密码？」进入重置弹窗：输邮箱 → 发送验证码（60s 倒计时）→ 输入验证码 + 新密码 → 提交重置。

### 5.11 提醒中心（顶部铃铛）
- 展示提醒列表（未读加粗、角标显示未读数）。
- 「全部已读」。
- 到点提醒轮询：每分钟检查到期的课程提醒；若开启浏览器通知并获得授权，弹出系统通知。

### 5.12 主题与响应式
- 亮色 / 暗色主题切换，选择持久化到 `localStorage`，下次访问生效。
- 顶部导航在窄屏折叠为移动端抽屉菜单。

## 六、数据缓存

- 使用 IndexedDB 做本地缓存封装（`src/utils/idb.js`）。
- 缓存**默认关闭**；可在「系统设置」中开启（开关写入 `localStorage` 的 `teac_idb_cache`，同时持久化到后端设置项），开启后各资源首次拉取、之后本地极速加载。

## 八、接口约定

- 统一返回结构 `{ code, message, data }`，`code === 0` 表示成功。
- `401` 时前端自动登出并跳转登录页。
- 分页接口走 POST 请求体（`pageNum/pageSize`），返回 `{ total, list }`。
- 时间字段以 ISO 格式（`YYYY-MM-DDTHH:mm:ss`）传输。
- 头像等上传接口以 `multipart/form-data` 提交，返回 `/uploads/**` 相对地址（开发环境经 vite 代理到后端）。

## 九、安全提示

- 后端 JWT 密钥、数据库密码、SMTP 凭据等敏感配置不应写入前端代码或提交仓库，详见后端 README 的「安全配置」章节。
- 前端仅持有登录返回的 `token`（存于 `localStorage`），不含任何密钥。
